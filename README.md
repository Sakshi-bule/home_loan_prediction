# home_loan_prediction
End-to-end banking ML pipeline predicting home loan default risk across 307,511 applications and 7 relational datasets. Engineered financial features, resolved data anomalies and severe class imbalance, benchmarked Logistic Regression, Random Forest, and LightGBM (0.7854 ROC-AUC), and deployed a live Streamlit web app for real-time risk screening.
